# 전투 도트 해상도와 배율 (이전 축소 방식)

사용자가 이 방식의 적용을 거부하고 새로 그린 픽셀아트 시안을 승인했다. 현재 동작은 `Documentation/ChiikawaApprovedArt.md`를 따른다. 아래는 이전 24도트 축소 시도의 기록이다.

이전 전투용 도트 마스터는 적/토벌대/쓰러짐 모두 긴 변 최대 48px, 표시 크기도 최대 48 UI px였다. 원본 PNG 크기는 서로 다르지만 전투 렌더러에서 동일한 48px 기준으로 변환했다. 전투는 SpriteRenderer가 아닌 CPU 픽셀 버퍼와 RawImage/네이티브 창 렌더링이므로 Unity Sprite의 PPU는 사용하지 않는다.

현재는 아래 공통 규격을 사용한다.

| 항목 | 값 |
| --- | --- |
| 전투 마스터 | 긴 변 최대 24도트, 가로세로 비율 유지 |
| 대상 | 토벌대 6명 × 전투/휴식/식사, 쓰러짐 6종, 적 10종 |
| 화면 표시 | 긴 변 최대 48 UI px 유지 |
| 도트 1칸 | UI 100%: 2×2px, 150%: 3×3px, 200%: 4×4px |
| 얼굴 프로필 | 기존 최대 32도트 유지 |
| 토벌 패널 | 기존 480×64 UI px 유지 |

`SubjugationArt.CombatPixelExtent=24`, `CombatDisplayExtent=48`, `CombatPixelScale=2`가 공통 기준이다. 표시 너비/높이는 각 마스터의 실제 정수 크기에서 계산하며, 위치와 공격 시 기울임도 같은 도트 격자에 맞춘다. 캐릭터마다 반올림을 따로 해서 도트 폭이 달라지는 문제를 피한다. 임의의 소수 배율에서는 물리 화면 픽셀 특성상 근접 픽셀 보간을 사용한다. 적 전용 초록·올리브 색은 캐릭터 얼굴 축소에 사용하지 않아 새 색이 얼굴에 섞이는 것을 방지한다.

원본 그림은 보존한다. 원본 아틀라스 크기: 캐릭터 1536×1024, 우사기 2172×724, 최초 적 1774×887, 신규 적 1774×887, 쓰러짐 2172×724. 원본 시트의 전체 크기와 게임에 표시하는 한 캐릭터의 도트 해상도는 서로 다른 값이다.

검증은 실제 34개 전투용 프레임 전체에 대해 24도트 상한과 2/3/4배 확대 시 픽셀 블록의 일치를 확인한다. 프로필 6종의 32도트 설정도 확인한다.
