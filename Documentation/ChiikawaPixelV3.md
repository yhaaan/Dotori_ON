# 캐릭터 도트 v3와 고용창 정리

Built-in ImageGen으로 v2 시트를 참고한 도트를 새로 생성했다. 확정 파일:

- `Assets/Resources/DOTORION/Events/Art/ChiikawaCharacters-v3.png`: 공통 6×4 시트. 우사기 이외의 다섯 캐릭터에 사용한다.
- `Assets/Resources/DOTORION/Events/Art/UsagiCanonicalMouth-v3.png`: 우사기 전투·휴식·식사·얼굴 시트. 모든 우사기 표시가 이 파일을 사용한다.

전투는 최대 48px, 얼굴은 최대 32px의 도트 원형으로 정리한다. 색은 공통 22색 팔레트, 가장자리는 투명/불투명으로 정리하고 배율 변경 시 Point 방식으로 확대한다. 도트 결과를 크기별로 캐시하여 매 프레임 변환하지 않는다.

고용 창의 캐릭터 이름 아래 설명, 장비 설명, 하단 설명 문구를 제거했다. 미고용 캐릭터 이름 뒤의 중복 상태 문구도 제거하고 고용 버튼에서 상태를 표시한다. 이름·레벨·얼굴·출전/구매 버튼은 유지한다. 설명을 없앤 만큼 창 높이를 306px에서 274px로 줄였다.

## 우사기 원작 확인

[공식 애니메이션 캐릭터 그림](https://www.anime-chiikawa.jp/images/characters/img_charapage.png)의 우사기를 기준으로, 닫힌 둥근 윗입술과 중심 아래에서 오른쪽으로 휘어지는 선을 반영했다. 전투·휴식·얼굴에서는 이 형태를 유지하며 분홍색 입 안·혀를 쓰지 않는다. 식사에서는 주먹밥이 입 전체를 가린다. 다른 캐릭터의 벌린 입을 공용으로 사용하지 않는다.
