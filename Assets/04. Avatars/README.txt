프로필 아이콘 이미지를 넣는 폴더.

여기에 PNG를 넣으면 임포트 설정이 자동으로 잡히고,
`Team Overlay > Refresh Avatar Catalog From Folder` 를 한 번 누르면
`Resources/TeamOverlay/TeamAvatarCatalog.asset` 목록이 이 폴더 내용으로 갱신된다.
하위 폴더까지 함께 훑는다.

## 어디에 넣나

- 일반 그림(그라데이션, 안티에일리어싱 있는 그림): 이 폴더 바로 아래.
  128x128 정사각형 권장. Bilinear + 밉맵으로 들어온다.
- 픽셀아트: `Pixel/` 하위 폴더.
  24x24 정사각형 권장(16x16, 48x48도 됨). Point 필터 + 밉맵 없음으로 들어온다.

아이콘은 카드에서도 선택창에서도 48x48로 그려진다. 그래서 픽셀아트는 48x48이면
1:1, 24x24면 2배, 16x16이면 3배로 정확히 확대되어 픽셀이 뭉개지지 않는다.
32x32나 40x40처럼 48의 약수가 아닌 크기는 픽셀 폭이 들쭉날쭉해진다.

## 공통

- 정사각형, 투명 배경 PNG.
- 파일 이름이 곧 서버에 저장되는 키다. 영문/숫자/. _ - 만, 64자 이하.
  한글 이름은 서버가 거부하므로 쓰면 안 된다. `default`도 예약어라 쓸 수 없다.
- 파일 이름을 바꾸면 그 아이콘을 쓰던 사람의 설정이 초기화된다.
