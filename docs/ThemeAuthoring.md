# 테마 제작

Unity 메뉴 **DOTORI ON → 테마 편집기**를 열거나 테마 SO를 선택합니다.

## 기본 팔레트

처음 보이는 것은 **공통 색상 19개**입니다. 창·카드·글자·강조·상태·버튼 색을 한 번씩 지정하면 같은 역할의 UI에 함께 적용됩니다. 반복되는 카드와 달력 셀을 각각 수정할 필요가 없습니다. 달력·랭킹이 코드에서 읽는 상태 팔레트도 같은 설정을 사용합니다.

수정하지 않은 역할은 각 UI의 기존 색을 보존합니다. `복원`으로 공통 변경을 해제할 수 있습니다. 투명도는 원본 값을 유지하고, 원색 스프라이트의 흰 틴트는 글자색과 함께 바뀌지 않습니다. 그림 자체에 배경색이 들어 있는 에셋은 아래 이미지 교체를 사용합니다.

## 이미지 교체

**이미지 교체** 탭은 같은 원본 Sprite를 하나로 묶습니다. 원본 옆에 새 Sprite를 넣으면 같은 이미지를 사용하는 UI와 상태 이미지 필드에 함께 적용됩니다. 새 이미지 슬롯을 비우면 원래 이미지로 돌아갑니다.

`팔레트 / 틴트 유지`는 기본적으로 켜져 있습니다. 정적 이미지에 색을 직접 그려 넣었다면 끄면 흰 틴트를 사용합니다. 코드가 관리하는 상태색은 기본 팔레트의 해당 상태색을 편집하세요. 사용자가 고른 아바타는 일괄 교체에서 제외됩니다.

새 이미지의 크기·피벗·9-slice Border를 기존 이미지와 맞추면 레이아웃이 유지됩니다. 미리보기는 이미지 비교용이며 실제 배치와 가독성은 Play 모드에서 확인합니다.

## 개별 예외 (고급)

특정 UI만 다르게 꾸밀 때 사용합니다. 1,024개의 원본 연결 정보는 이 탭에만 표시됩니다.

- `Original`: 이 UI만 기준 모습으로 고정합니다.
- `Tint`: 이 UI만 지정한 색을 사용합니다.
- `SpriteSwap`: 이 UI만 지정한 이미지와 색을 사용합니다.
- **개별 설정 해제**: 다시 공통 팔레트와 이미지 교체를 따릅니다.

적용 우선순위는 **개별 예외 → 공통 설정 → 기준값**입니다. 이전 버전에서 만든 개별 설정은 그대로 유지됩니다. 상태 코드가 관리하는 항목은 해당 View의 상태 필드 또는 기본 팔레트로 설정합니다.

## 생성과 적용

1. **새 테마** 또는 **테마 복제**로 테마 SO를 준비합니다.
2. 기본 팔레트와 필요한 이미지 교체를 설정합니다.
3. **저장 → 기본 테마로 지정**하면 다음 실행에 적용됩니다.
4. Play 모드에서는 **실행 중 적용**으로 확인할 수 있습니다. 상태 UI는 다음 상태 갱신에 반영됩니다.

## 새 UI 추가

**기준 UI 수집 / 새 항목 추가**로 `Assets/02. Prefabs`의 UI를 연결합니다. 기존 ID와 기준값은 보존되므로 기존 테마가 유지됩니다. 프리팹을 재생성해 바인딩 자체를 제거하는 작업은 연결 ID도 없애므로 주의하세요.

기존 카탈로그는 재수집 없이 공통 팔레트를 사용할 수 있습니다. `ThemeRoleRules`는 상태 필드의 의미, 글자/이미지 종류, 기존 색과 위치를 기준으로 역할을 결정합니다. 같은 RGB라도 글자와 원색 이미지, 상태 필드는 다르게 취급합니다. 새 UI의 역할이 특수하면 해당 바인딩의 `ColorRole`을 지정하거나 이 분류 규칙을 확장할 수 있습니다.

기준 목록: `Assets/Resources/DOTORION/ThemeCatalog.asset`

테마 SO: `Palette`(19개 역할의 변경값), `Sprites`(원본별 이미지 교체), `Overrides`(개별 예외). 기존 색상 필드는 이전 데이터 호환과 코드 기본값으로 유지합니다.

런타임 전환: `DOTORIONPalette.Use(theme)`.

## 설정 패널에서 고르기

설정 패널의 "설정" 제목 옆에 테마마다 둥근 버튼이 하나씩 있습니다. 버튼 i번은 `DOTORIONApp`의 `_themes`(`Resources/DOTORION/DOTORIONApp.prefab`) i번 테마이고, 칠해진 색은 그 테마의 `Accent`입니다. 새 테마를 버튼으로 고르게 하려면 목록에 넣고 `Display Name`을 채우세요. 다른 테마와 구분되는 강조색이 필요합니다. 고른 테마는 `PlayerPrefs`(`DOTORION.Theme`)에 에셋 이름으로 저장되어 재시작해도 유지됩니다.
